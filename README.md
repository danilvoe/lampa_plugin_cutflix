# Cutflix для Lampa

Плагин добавляет в Lampa отдельный раздел **Cutflix** для каталога и просмотра видео.

## Оригинальный сайт

Плагин предназначен для сайта [cutflix.ru](https://www.cutflix.ru).

## Установка

Ссылка на плагин:

```text
https://cdn.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@main/cutflix.js
```

## Сброс кэша

Откройте в браузере:

```text
https://purge.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@main/cutflix.js
```

Затем в Lampa: **Настройки → Расширения** → удалить и добавить ссылку заново → перезапустить.
