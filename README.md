# Cutflix для Lampa

Плагин добавляет в Lampa отдельный раздел **Cutflix** для каталога и просмотра видео с сайта [cutflix.ru](https://www.cutflix.ru).

## Возможности

- отдельный пункт в главном меню;
- каталог публикаций и категорий с постраничной загрузкой;
- список сезонов внутри категории;
- карточка публикации: постер, описание, год, длительность и просмотры;
- воспроизведение HLS через встроенный плеер Lampa;
- автоматический плейлист сезонов;
- кэширование запросов и обработка ошибок;
- поддержка русского, украинского и английского языков;
- настройка адреса сайта или зеркала.

## Установка

1. Откройте Lampa.
2. Перейдите в **Настройки → Расширения**.
3. Добавьте ссылку на плагин:

   ```text
   https://cdn.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@main/cutflix.js
   ```

   Запасные адреса:

   ```text
   https://raw.githack.com/danilvoe/lampa_plugin_cutflix/main/cutflix.js
   https://raw.githubusercontent.com/danilvoe/lampa_plugin_cutflix/main/cutflix.js
   ```

   Ссылка `raw.githubusercontent.com` может не работать в современных
   браузерах и Lampa на Chromium: GitHub отдаёт файл как `text/plain`,
   и браузер блокирует его загрузку как скрипта. В этом случае
   используйте ссылку jsDelivr или raw.githack.

4. Перезапустите Lampa.
5. В главном меню появится пункт **Cutflix**.

## Настройка

В настройках Lampa появится раздел **Cutflix** с параметром:

- **Адрес Cutflix** — основной адрес сайта или зеркало. По умолчанию: `https://www.cutflix.ru`.

## Требования

- Lampa 3.4+;
- доступ к API `cutflix.ru`;
- поддержка HLS в Lampa или на устройстве.

## Решение проблем

Если на телевизоре нет звука или не появляется выбор качества, плагин
использует программный HLS-плеер Lampa (hls.js), который поддерживает
отдельные аудиодорожки и выбор качества. На Tizen (в том числе в
MediaStation X) на время просмотра Cutflix плагин переключает Lampa на
встроенный плеер и возвращает прежнюю настройку после закрытия.

Если в логе Lampa есть строка `[Cutflix] quality off <платформа> <плеер>`,
значит WebView устройства не поддерживает MSE и качеством управляет
системный плеер — в этом случае используйте приложение Lampa для Android TV
или внешний плеер.

Если изменения в плагине не применяются, обновите адрес в расширениях:
jsDelivr может отдавать кэш до 12 часов. Используйте raw.githack или
добавьте к адресу параметр `?v=2`.
