# Cutflix для Lampa

Плагин добавляет в Lampa отдельный раздел **Cutflix** для каталога и просмотра видео с сайта [cutflix.ru](https://www.cutflix.ru).

## Возможности

- отдельный пункт в главном меню;
- каталог публикаций и категорий с постраничной загрузкой;
- список сезонов внутри категории;
- карточка публикации: постер, описание, год, длительность и просмотры;
- воспроизведение HLS через встроенный плеер Lampa;
- автоматический плейлист сезонов;
- кэширование запросов и обработка ошибок;
- поддержка русского, украинского и английского языков;
- настройка адреса сайта или зеркала.

## Установка

1. Откройте Lampa.
2. Перейдите в **Настройки → Расширения**.
3. Добавьте ссылку на плагин:

   ```text
   https://cdn.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@a53ac00/cutflix.js
   ```

   Адрес с хэшем коммита всегда отдаёт указанную версию, без задержки
   кэша CDN. При обновлении плагина замените хэш `a53ac00` в адресе на
   хэш нового коммита.

   Ссылка `raw.githubusercontent.com` может не работать в современных
   браузерах и Lampa на Chromium: GitHub отдаёт файл как `text/plain`,
   и браузер блокирует его загрузку как скрипта. В этом случае
   используйте ссылку jsDelivr с хэшем коммита.

4. Перезапустите Lampa.
5. В главном меню появится пункт **Cutflix**.

## Настройка

В настройках Lampa появится раздел **Cutflix** с параметром:

- **Адрес Cutflix** — основной адрес сайта или зеркало. По умолчанию: `https://www.cutflix.ru`.

## Требования

- Lampa 3.4+;
- доступ к API `cutflix.ru`;
- поддержка HLS в Lampa или на устройстве.

## Решение проблем

HLS-поток Cutflix использует fMP4 с отдельным инициализирующим сегментом
(`#EXT-X-MAP`) и байтовыми диапазонами (`#EXT-X-BYTERANGE`). На телевизорах
Samsung и в Media Station X браузер отправляет CORS-preflight (OPTIONS) на
запрос этого сегмента с заголовком `Range`. Сервер Cutflix отвечает на
такой OPTIONS кодом 405 без CORS-заголовков, поэтому hls.js не может
загрузить инициализирующий сегмент и видео не запускается.

Плагин обходит это: при загрузке плейлиста он подменяет адрес
инициализирующего сегмента на первый медиасегмент с того же CDN
(`reflector.cutflix.ru` / `mirror.cutflix.ru`). Эти хосты корректно
отвечают на preflight, а начало медиафайла побайтно совпадает с
инициализирующим сегментом. Качество и аудиодорожки при этом остаются
доступны.

На Tizen плагин на время просмотра Cutflix переключает Lampa на встроенный
плеер (hls.js) и возвращает прежнюю настройку после закрытия. На телевизорах
плагин ограничивает буфер hls.js 60 секундами вперёд: без этого аудиобуфер
переполняется, hls.js сбрасывает звук, и остаётся только картинка. Если
hls.js недоступен (MSE не поддерживается), плагин открывает прямой файл
через штатный плеер Tizen. Если hls.js падает с фатальной ошибкой, плагин
также переключается на прямой файл.

Строки в логе Lampa:

- `[Cutflix] hls playlist patch installed` — включён обход preflight;
- `[Cutflix] init segment redirected to media host` — плейлист переписан;
- `[Cutflix] quality on ... inner` — используется hls.js на Tizen;
- `[Cutflix] tv buffer limits applied` — включён лимит буфера для ТВ;
- `[Cutflix] native file fallback` — hls.js недоступен, открыт прямой файл;
- `[Cutflix] hls failed, switching to native file` — hls.js не смог
  воспроизвести поток, открыт прямой файл;
- `[Cutflix] quality off <платформа> <плеер>` — программный HLS недоступен,
  качеством управляет системный плеер.

Если изменения в плагине не применяются, сбросьте кэш CDN и Lampa —
см. раздел «Сброс кэша».

## Сброс кэша

Если после обновления плагина изменения не применяются, значит старая
версия закэширована на CDN или в самой Lampa.

1. Очистите кэш jsDelivr. Откройте в браузере:

   ```text
   https://purge.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@main/cutflix.js
   ```

   В ответе должно быть `"status": "finished"`.

2. Если адрес `@main` всё равно отдаёт старую версию, используйте адрес,
   привязанный к коммиту:

   ```text
   https://cdn.jsdelivr.net/gh/danilvoe/lampa_plugin_cutflix@a53ac00/cutflix.js
   ```

   Такой адрес всегда отдаёт указанную версию. Хэш `a53ac00` можно
   заменить на хэш более нового коммита.

3. В Lampa откройте **Настройки → Расширения**, удалите старый адрес
   плагина, добавьте новый и перезапустите Lampa.

4. Если в Lampa включён офлайн-кэш расширений, очистите данные приложения
   Lampa в настройках устройства или переустановите плагин.

Признак загруженной версии с управлением качеством — строка
`[Cutflix] quality on/off ...` в логе Lampa.
